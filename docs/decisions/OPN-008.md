# OPN-008: Retensi, e-sign, klasifikasi data, dan RPO/RTO

- Status: DRAFT
- Owner: Legal/Records/TI
- Approver: TBD
- Tanggal keputusan: TBD

## Keputusan yang dibutuhkan

- Klasifikasi data per entity/attachment dan aturan akses.
- Retention, legal hold, archival, disposal, dan audit evidence.
- Status hukum bukti persetujuan elektronik dan spesimen tanda tangan visual; kebutuhan tanda tangan
  elektronik tersertifikasi (PSrE) serta tingkat assurance.
- RPO/RTO, backup, restore validation, dan ownership disaster recovery.

## Keputusan

Belum diputuskan. Data tidak boleh dihapus otomatis berdasarkan asumsi retensi.

Arahan implementasi attachment dan bukti persetujuan per 22 September 2026 (BRD v1.8 DEC-125):

- Tidak ada tanda tangan elektronik tersertifikasi. Administrator dapat mengunggah spesimen tanda
  tangan visual (PNG) berversi per pengguna; versi exact, hash, dan byte dibekukan pada snapshot
  Sponsor (Bagian 3) serta evidence SO/Officer dan Manager (Bagian 7) lalu dicetak bersama nama,
  jabatan, dan waktu. Bentuk ini dilabeli **bukti persetujuan elektronik**, bukan tanda tangan digital
  tersertifikasi, sampai Legal memutuskan lain.
- Tanda tangan Pelaksana Pekerjaan, Bagian 6, dan Bagian 8–10 tetap pada hardcopy.
- Lampiran menerima PDF, JPEG, dan PNG; setiap file menyimpan SHA-256, kategori, kode dokumen,
  metadata, target versi, PrintPackage (untuk hardcopy), lineage penggantian, dan evidence scan.
- Semua role yang telah lolos authorization parent PTW dan scope lokasi boleh mengunduh lampiran
  yang berstatus `CLEAN`; file selain `CLEAN` tidak dapat diunduh. Setiap unduhan dokumen resmi
  menghasilkan audit event.
- Sponsor pemilik PTW dapat menambah atau melakukan logical removal hanya saat `DRAFT` atau
  `REVISION_REQUIRED` (dan mengunggah `SIGNED_FIELD_COPY` saat `ISSUED`/`SUSPENDED`/`EXPIRED` atau
  tindak lanjut penutupan); file historis tidak dihapus fisik.
- Retention/disposal serta storage dan malware scanner production ditunda. Baseline Development
  menyimpan file pada private filesystem dan, dengan `RequireMalwareScan=false`, memakai pemindai
  upload lokal tepercaya; produksi tetap fail-closed tanpa scanner resmi. UI tidak menampilkan status
  teknis scan pada setiap lampiran.

Status record tetap `DRAFT` karena klasifikasi data, retention/legal hold, status hukum bukti
persetujuan visual, platform production, RPO/RTO, approver formal, dan bukti pengesahan belum tersedia.
